# StudiBase experiments

This folder contains the smaller programs and original prototype used while learning and building StudiBase. They explore individual ideas such as reading records from a file, sorting structures, writing sorted output, and combining the features into one menu-based program.

`studibase_prototype.c` is the original monolithic prototype. The complete, maintained program is [`../studiBase.c`](../studiBase.c).

These files are preserved as development history and are not included in the main build. They may not contain the validation and error handling used by the completed program.
